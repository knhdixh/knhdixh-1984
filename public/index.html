  1. 01 Install Tampermonkey from the list above.
  2. 02 In chrome://extensions, open Tampermonkey’s details and turn on Allow user scripts.
  3. 03 Press Install below. Tampermonkey opens the script in a new tab; press Install there.
  4. 04 Or open the gist, press Raw on anti-visibility-cloak.user.js, and install from the Tampermonkey tab.
  5. 05 No Tampermonkey tab? Copy the gist’s code, open Tampermonkey → Create a new script, replace everything, and save.
  6. 06 Disable any older copy, then reload the page you want it on.
